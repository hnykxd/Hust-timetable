安装步骤

  1. 点上面的「下载安卓版 APK」（微信里请先在浏览器打开）。
  2. 下载完成后点安装包，系统提示「未知来源 / 风险应用」时，选择允许或继续安装。

常见问题

提示「未知来源」或「风险应用」怎么办？

这是安卓对非应用商店安装包的统一提示，不是 App 有问题。小米 / Redmi（HyperOS、MIUI）点继续安装；华为 / 荣耀需要在「设置 → 安全 → 更多安全设置 → 外部来源应用下载」里允许。

以后有新版本，需要卸载了重装吗？

不需要，也请不要卸载：卸载会清空已导入的课表与日程。直接下载新版 APK 覆盖安装即可，课程、日程和设置都会保留（同一个签名才能覆盖）。

为什么安装包有 50 多 MB？

APK 里打包了 Flutter 运行引擎，并同时包含 arm64 / armv7 / x86_64 三种 CPU 架构。之后可以单独出 arm64 版本（约 25 MB），只给新款手机用。

装完打不开 / 闪退？

需要 Android 8.0 以上、64 位系统。如果闪退，先对照下面的 SHA256 确认文件下载完整，再重新下载安装；仍不行可以在群里反馈机型和系统版本。

要联网吗？会收集我的信息吗？

看课表本身不需要联网；导入课表（企业微信 / 教务）和天气条需要联网。App 不申请定位、通讯录、相册权限，课表与日程只保存在手机本地（Hive 数据库），没有上传到任何服务器。

闹钟提醒没响？

提醒默认是关闭的：到「设置 → 提醒设置」打开「上课与日程提醒」，并按提示允许通知和精确闹钟权限。小米 / 华为还需要在系统的电池优化里把本应用设为「不限制后台」。
